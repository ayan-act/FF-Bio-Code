## 📖 About

**FF Bio Code** helps Free Fire players discover, preview, copy, and customize **premium bio styles** in seconds — all from a fast, modern, and user-friendly Android app.

Based on the content available on the [official website](https://ffbiocodes.com/), the app brings together stylish bio codes, colour codes, trending collections, live preview tools, and one-tap copy functionality. This repository distributes the Android APK; the application source code and Gradle project are not included here.
